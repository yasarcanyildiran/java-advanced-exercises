## Vérifier vos exercices

| Commande                              | Effet                            |
|---------------------------------------|----------------------------------|
| `./gradlew td1`                       | Lance les tests du td1           |
| `./gradlew check`                     | Lance tous les tests             |
| `./gradlew td3 --tests "ExoListTest"` | Lance les tests d'ExoList du td3 |

Les résultats apparaissent dans le terminal, ou bien en ouvrant le fichier 
`build/reports/tests/td1Test/index.html` (par exemple) dans un navigateur.

Les tests peuvent aussi être lancés depuis l'IDE.
